# Ізольований локальний геокодер PRG

Повністю локальний прототип: Python standard library + SQLite FTS5, HTML/CSS/JS без CDN.
Робочі компоненти Transit Alert не підключені й не змінюються.

## Вулиці та поступове введення

Індекс містить **2580 унікальних вулиць** окремо від усіх 96009 адрес:
2570 із державного шару PRG_Ulice та 10 явно позначених груп реальних адресних точок.
PRG_Ulice наявний у 10 із 16 локальних пакетів; відсутній у Konopnica, Strzyżewice,
Lubartów, Jabłonna, Spiczyn, Wojciechów. Нових завантажень немає.

Для вулиці збережено TERC, SIMC, ULIC, стабільний складений ID, усі початкові ID/поля,
геометрію MultiLineString у CS92 та репрезентативну точку на цій геометрії
(половина сумарної довжини сегментів). Межі вулиць або будинки не вигадуються.
Групи без окремого об'єкта вулиці мають origin=PRG_address_group:
координати одного справжнього адресного запису, найближчого до середнього положення групи.
Це не підтверджена геометрія вулиці; origin і representative_method присутні в API.

Запити li → lip → lipo → lipowa повертають насамперед унікальні вулиці;
Lipowa 12 — будинки; Motycz 69B — як і раніше безвуличну адресу.
Однакові назви різних SIMC не об'єднуються. Для однакових назв навіть у тій самій місцевості
використовується TERC/SIMC/ULIC. Результат має type=street або type=address.
У першому випадку house_number порожній, coordinate_kind=street_representative.
У другому coordinate_kind=address_point. Координати вулиці не означають конкретного будинку.

Вибір вулиці показує її координати й залишає назву з пробілом у полі:
можна одразу дописати номер. Редагування приховує попередній вибір;
запізніла відповідь не замінює актуальні підказки. Клавіатура й клік працюють для обох типів.
Окремого перенесення кнопки ↖ з Transit Alert в цей прототип не виконано.

## Відкрити

Поточний прототип: **http://127.0.0.1:32775/**

З кореня репозиторію:

```bash
python3 experiments/local-geocoder/control.py start --port 32775
python3 experiments/local-geocoder/control.py status
python3 experiments/local-geocoder/control.py stop
```

Якщо порт зайнятий, запуск завершиться помилкою без втручання в інший процес.
Для автоматичного вибору вільного порту: `python3 experiments/local-geocoder/control.py start`.
Команда виведе точний URL. PID, URL і журнал містяться в `run/server.json`, `run/server.log`.
Повторний start повертає URL уже запущеного прототипу. Stop перевіряє командний рядок процесу перед сигналом.
Можливий запуск на передньому плані: `python3 experiments/local-geocoder/server.py --port 32775`; зупинка Ctrl+C.
Адреса прив'язки завжди 127.0.0.1; опції зовнішньої прив'язки немає. Автозапуску після перезавантаження немає.

## Дані й побудова

Індекс охоплює **усі 96 009 адрес, 290 SIMC, 16 гмін**, включно з адресами поза буфером 1 км.
15 пакетів: `/tmp/transit-geocoder-study/step3-packages/*.zip`;
Jastków: `/tmp/transit-geocoder-study/jastkow-address-package.zip`.
Точний список шляхів і SHA256 — `/tmp/transit-geocoder-study/step3-download.json` та метадані SQLite.
Всі 16 шляхів перевірено; Жодних повторних завантажень. Оригінальні пакети не змінюються.

```bash
python3 experiments/local-geocoder/build.py
```

Для побудови використано вже наявний pyproj із `/tmp/transit-geocoder-study/lib` (можна також мати встановлений pyproj).
Нічого нового не встановлено. Для подальшого пошуку pyproj і вихідні ZIP не потрібні.
Повторна побудова перевіряє існування й SHA256 усіх пакетів, використовує тимчасовий файл та атомарно замінює SQLite.
Не запускайте побудову одночасно у двох процесах. Для узгоджених перевірок зупиніть прототип перед перебудовою.
Файли в /tmp можуть зникнути після очищення системи; вже побудована база залишається в `data/addresses.sqlite`.

У SQLite збережено:
- початковий словник усіх полів DBF як `raw_prg`, початковий версійний `source_id`;
- стабільний `id`: простір імен PRG + UUID без часової версії;
- SIMC, TERC, населений пункт, вулицю, номер будинку, пакет-джерело;
- вихідні x/y CS92 та перераховані lon/lat WGS84;
- окремі нормалізовані поля лише для пошуку; початкове написання не змінене.

## API

```bash
curl http://127.0.0.1:32775/health
curl http://127.0.0.1:32775/stats
curl --get --data-urlencode 'q=Biłgorajska 24' --data 'limit=10' http://127.0.0.1:32775/search
```

`/search` повертає query, results, warning, elapsed_ms.
Кожен результат: type, coordinate_kind, origin, representative_method, ulic, id, source_id, display_name, locality, simc, terc, street, house_number, lat, lon, match_rank.
Порожній запит → 200 і порожній список. Некоректні запити → 400.
Максимум 200 символів, 12 слів, limit=1–50 (більший додатний limit обмежується до 50).
Голі номери та однолітерні запити відхиляються. Тайм-бюджет SQL — 2 с.
Під час пошуку немає мережевих клієнтів, сторонніх сервісів чи звернень до Transit Alert.

## Поведінка пошуку

Нормалізація регістру, пробілів та польської діакритики, зокрема ł → l.
Ігноруються позначення ul./ulica, al./aleja/aleje, pl./plac.
Номер будинку відокремлюється від назви й не бере участі в текстовому FTS-пошуку.
FTS5 unicode61/prefix знаходить початки слів, окремий trigram — внутрішні фрагменти.

Пріоритет: точна назва/повна комбінація вулиці й місцевості, точне кінцеве ім'я вулиці
(наприклад Narutowicza), початок назви, початки слів, внутрішні фрагменти.
У межах текстового пріоритету точний номер стоїть перед продовженням номера (12 перед 12A).
Ранжування виконується перед LIMIT над усіма кандидатами.
За однакового текстового рангу Lublin має статичний пріоритет; GPS/транспортні відстані не використовуються.
Чисту функцію rank можна доповнити просторовим критерієм згодом.

Для звуження неоднозначних назв додайте населений пункт: `Lublin Lipowa 12`, `Świdnik Narutowicza 12`.
Однакові назви в різних гмінах збережено окремо; підказки показують SIMC і TERC.
Квартира з явним m./lok. відкидається з попередженням: `Lipowa 12 m. 3` → будинок 12.
`12/3` шукається лише як ТОЧНИЙ початковий номер PRG із «/», без припущення про квартиру;
якщо такого номера немає в наборі, результат порожній. У PRG є 122 справжні номери з «/».
Номери з дефісами також збережені й шукаються як задані в джерелі.

Прототип не виправляє орфографічні помилки, не розпізнає квартири й не перевіряє існування адреси поза PRG.
Відсутність результату означає відсутність відповідного збігу в цьому локальному зрізі.
Номер очікується наприкінці: `Lublin Lipowa 12`; довільне переставляння номера всередину запиту поки не підтримане.
Покриття не є підтвердженням пішохідної доступності.

## Перевірки

```bash
python3 experiments/local-geocoder/test_geocoder.py
python3 experiments/local-geocoder/test_streets.py
node experiments/local-geocoder/test-ui.mjs
```

HTTP-тест перевіряє щонайменше 40 запитів, порядок результатів, поля/координати за вихідними пакетами,
попередні незалежні координати дослідження, негативні запити, обмеження, /health, /stats, HTML і JS/CSS.
Вимір HTTP включає з'єднання, обробку й декодування JSON; 200 послідовних запитів, limit=10, переважно теплий кеш.
Тест вулиць перевіряє поступове введення, діакритику, неоднозначні назви, типи результатів і всі 2580 репрезентативних точок за джерелом.
JS-тест без браузера перевіряє вибір вулиці та дописування номера, debounce, стрілки/Enter/Escape, вибір координат, застарілі відповіді та порожні результати.
Візуальну перевірку браузером не виконано: браузерний інструмент середовища недоступний.
Для ручної перевірки введіть `bilgorajska 24`, виберіть підказку стрілкою/Enter:
очікується Biłgorajska 24, Lublin та координати. Потім перевірте `Motycz 69B` і `Lipowa 99999`.

Результати вимірів і справжні приклади: `REPORT.md`, деталізація кожного запиту — `data/test-results.json`.
SQLite, журнали, PID і результати тестів локально ігноруються через .gitignore; Git-комітів не створено.
